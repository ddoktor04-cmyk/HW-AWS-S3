AWS S3 · Static Website Hosting

Static Web Site

на основі сервісу AWS S3 · hwbarabash1.pp.ua

Що це?

Ця сторінка — статичний веб-сайт, розміщений у Amazon S3 через механізм Static Website Hosting. HTML, CSS та JavaScript віддаються без жодного веб-сервера чи віртуальної машини — лише S3 bucket з увімкненою публічною політикою читання.

Як це працює

S3 Bucket

Об'єкти зберігаються в бакеті, доступ до якого відкритий лише на читання (s3:GetObject).

Website Endpoint

AWS публікує HTTP-ендпоінт вигляду http://<bucket>.s3-website-eu-north-1.amazonaws.com.

Index та Error документи

Конфігурація website hosting вказує index.html як головну сторінку та документ помилок.

Власний домен

Домен hwbarabash1.pp.ua прив'язується CNAME-записом до S3 website endpoint.

Переваги підходу

  • Мінімальна вартість: оплата лише за зберігання та запити
  • Не потрібні сервери, ОС чи адміністрування
  • Масштабування «з коробки» — S3 витримує будь-який трафік
  • Інфраструктура описана кодом Terraform (IaC)
  • Весь сайт — це прості файли в бакеті
